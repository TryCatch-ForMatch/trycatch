# Documento Estratégico --- Governança de Dados e LGPD

Classificação: Documento Estratégico\
Camada: 1 --- Estratégia

## 1. Objetivo

Estabelecer princípios de proteção de dados e conformidade com LGPD.

## 2. Dados Coletados

-   Dados cadastrais básicos.
-   Dados de participação em projetos.
-   Feedbacks vinculados a projetos.

## 3. Princípios

-   Minimização de dados.
-   Finalidade explícita.
-   Transparência.
-   Registro de auditoria.

## 4. Segurança

-   Autenticação segura.
-   Controle de permissões por papel.
-   Logs de ações críticas.

## 5. Direitos do Usuário

-   Solicitação de exclusão de conta.
-   Acesso aos próprios dados.
-   Correção de dados pessoais.

## 6. Evolução

A maturidade de conformidade será ampliada progressivamente.
